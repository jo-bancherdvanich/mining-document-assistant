# Mining Document Assistant Prototype

A clickable prototype that shows how a RAG-style document assistant could work for a mining engineering consultancy. Ask a question, and the page shows an answer and the relevant source files.

**This is a simulation.** It uses simple word matching and no AI. All files, sites and figures are made up.

## Run the tests

Requires Node.js. There's nothing to install.

```bash
npm test
```

## Publish on Vercel

1. Push this repository to GitHub.
2. In Vercel, choose **Add New > Project** and import the repository.
3. Set the framework preset to **Other** and leave the build command empty.
4. Choose **Deploy**.
